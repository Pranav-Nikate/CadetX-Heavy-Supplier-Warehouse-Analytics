# Heavy Supplier, Inventory & Warehouse Analytics

## Project Overview

**Programme:** CadetX Virtual Work Experience  
**Duration:** 12 Weeks  
**Domain:** Data Analytics, Business Intelligence & Data Science

### Project Objective

The objective of this project is to analyse supplier, inventory, sales, purchase and warehouse data to discover business insights and improve operational efficiency.

### Tools & Technologies

- Python
- Pandas
- NumPy
- Jupyter Notebook
- SQL
- Excel
- Power BI
- GitHub

### Project Scope

1. Data collection and exploration
2. Data cleaning and preprocessing
3. Data integration and validation
4. Product and inventory analysis
5. Warehouse performance analysis
6. Supplier performance analysis
7. Customer analytics
8. Demand forecasting and predictive analytics
9. Business intelligence dashboards
10. Business recommendations and final reporting

### Project Structure

The project is organised into weekly sprints over 12 weeks, with documentation, analysis notebooks, reports and dashboards.

### Expected Outcome

Develop practical data analytics skills and deliver portfolio-ready insights, visualisations and business recommendations for supply chain operations.
